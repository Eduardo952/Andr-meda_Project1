# Guias locais deste projeto

Instalados a pedido do usuário, pelo instalador oficial de skills do Codex, a partir de:

https://github.com/gamedev-skills/awesome-gamedev-agent-skills

- `create-game-assets`: consistência, silhueta, transparência, procedência e verificação da arte.
- `game-ui-ux`: dimensionamento, hierarquia, legibilidade e fluxo da interface.
- `level-design`: orientação visual, ensino por ações e decoração fora das rotas.

Esses são guias comunitários de desenvolvimento, **não fontes científicas nem material da NASA**. Instalação local em `Tools/Skills`, sem alterar skills globais. As decisões específicas de Unity, código e design continuam no projeto. Instruções genéricas de testar todos os menus não se sobrepõem ao pedido do usuário de verificações focadas.

Aplicação e escolhas: `Assets/ARES/VISUAL_LEARNING.md`. Procedência científica: `Tools/ScienceEvidence/README.md`. Arte gerada: `Assets/ARES/Resources/ARES/UI/HudIcons/ART_DIRECTION.md`.
